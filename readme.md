## 🛠️ 【技术栈说明】
    🖥️ 前端技术栈 # Vue3 + Element-Plus + ECharts
    🧰 后端技术栈 # SpringBoot3 + MyBatis + Maven
    📦 数据库与管理工具 # MySQL + Navicat

## 🚀 快速启动指南

### 1️⃣ 前端启动（Vue3 + Vite）
    cd frontend
    npm install        # 安装依赖
    npm run dev        # 启动本地开发服务（默认端口 5173）


### 2️⃣ 后端启动（SpringBoot3 + MyBatis）
    cd backend
    mvn clean
    rm -rf target
    mvn spring-boot:run
